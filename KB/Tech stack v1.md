# Sales AI Agent — Tech Stack

> Created: April 1, 2026 | Updated: April 1, 2026

## Conversational AI Platform

The agent is built on a conversational AI platform with:

- Built-in vector knowledge base (RAG) for accurate, grounded answers
- Conversation flows designed for flexibility and control — each use case is implemented to balance natural dialogue with structured logic
- Native integrations with CRM, calendar, and messaging tools
- GDPR compliance and SOC 2 certification
- 24/7 cloud availability
- Chat widget that can be embedded on any website

## LLM Providers

The agent is powered by large language models from leading providers including Anthropic (Claude), OpenAI (GPT), Google AI (Gemini), and others.

Model selection is tailored per flow based on:

- **Logic complexity** — some flows require stronger reasoning and instruction-following capabilities
- **Context window requirements** — longer conversations or larger knowledge bases may require models with extended context
- **Model characteristics** — accuracy, rule adherence, response style, and consistency vary across models
- **Client's allocated budget** — model providers have different pricing tiers, and the selection balances performance with cost efficiency

## Integrations

The agent can connect to:

- CRM systems (e.g., HubSpot, Salesforce)
- Calendar tools (e.g., Cal.com, Calendly)
- Website platforms (WordPress, Webflow, custom-built)
- Messaging tools (Slack, email)
- Other tools depending on the client's stack — scoped during discovery

- Concurrent user capacity beyond typical B2B volumes
- Processing speeds for specific operations
