# Maintenance and Infrastructure Costs

> Created: May 11, 2026

## Post-Launch Platform & Infrastructure Costs

The project fee and monthly retainer cover Halo Lab's work only. **Platform subscriptions, AI model usage, and third-party integration tools are paid separately by the client** through their own accounts on each platform.

### What the client pays for separately

- **AI platform subscription** — The platform the agent runs on (e.g., Botpress) has its own pricing. This is billed directly by the platform provider, not by Halo Lab.
- **AI model usage** — Token or conversation-based costs depending on the platform. For example, Botpress charges based on tokens used (varies by model and query volume); other platforms may charge per resolved conversation regardless of message count.
- **Third-party integration tools** — Any external services connected to the agent (CRM, calendar, analytics) may have their own subscription costs.

### API keys

Whether the client needs to provide their own API keys depends on the integrations required. Halo Lab provides instructions on how to obtain and configure any API keys needed for the project.

### What determines the ongoing cost

The total post-launch infrastructure cost depends on:
- Complexity of the conversation flows
- Which AI model is selected
- Volume of conversations
- Number of integrations connected

Exact infrastructure costs are scoped during the discovery call based on the client's requirements.
